Wacken Metal Radio v4

Η έκδοση προσθέτει Netlify Function για ανάγνωση ICY StreamTitle από τα 5 streams.
ΠΡΟΣΟΧΗ: Η λειτουργία δεν ενεργοποιείται με απλό drag-and-drop ZIP/φακέλου στο Netlify Drop. Χρειάζεται deploy μέσω Git repository ή Netlify CLI που υποστηρίζει functions.
Επίσης ΔΕΝ έχει επαληθευτεί ότι οι σταθμοί στέλνουν ICY metadata. Αν δεν στέλνουν, δεν θα εμφανίζεται τραγούδι.
Για αναβάθμιση υπάρχουσας εγκατάστασης κρατήστε το ίδιο Netlify site και manifest id.
